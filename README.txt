CHESS RPG
=========

A role-playing game in a world where people settle conflict through chess—and
where every king changes the rules.


Root Reference Documents
------------------------

* AI_DESIGN_NORTH_STAR.txt
  Desired opponent behavior, opening principles, and scaling AI personality to
  a large king roster.

* PURE_DATA_AUTHORITATIVE_CORE_INTENT.txt
  Current rules architecture, exact implementation map, measured performance,
  engineering constraints, validation pointers, and the next optimization plan.

* CHESS_PRESENTATION_INTENT.txt
  The physical-board battle aesthetic, piece-art standard, hands, effects, and
  presentation guardrails.

* DIALOGUE_PRESENTATION_INTENT.txt
  Dialogue aesthetics, semantic architecture, authored text, portraits, choices,
  typography, and prototyping direction.

* PRESENTATION_SIZING_INTENT.txt
  Canonical UI composition, overworld scaling, fluid battle-board sizing,
  safe-area constraints, and mobile layout policy.

* IOS_DEVICE_TEST_ROADMAP.txt
  Operational checklist for installing and smoke-testing an iOS build. Unlike
  the intent documents, its toolchain and device details are time-sensitive and
  should be reverified before use.

These documents have deliberately separate scopes. Historical implementation
details belong in version control and tests rather than accumulating here as
permanent migration diaries.
